# Измерение скорости скачивания

Консольный скрипт на Python. Принимает URL, выполняет 10 последовательных
GET-запросов и полностью скачивает каждый ответ.

Выводит:
- среднее время запроса в секундах;
- общий объём скачанных данных в байтах;
- скорость скачивания в Мбит/с.

## Установка

Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Передайте адрес файла первым аргументом:

```bash
python speed_test.py "https://www.python.org/static/img/python-logo.png"
```

Этот адрес подходит для проверки запуска.
Для измерения скорости рекомендуется прямая ссылка на большой файл.

Справка:

```bash
python speed_test.py --help
```

## Расчёт результатов

Среднее время запроса — сумма длительностей всех 10 запросов,
делённая на 10.

Скорость скачивания рассчитывается по формуле:

```text
Скорость (Мбит/с) = общий объём (байт) × 8 / суммарное время (с) / 1 000 000
```

1 Мбит/с — 1 000 000 бит в секунду.

Измеряется время от начала запроса до полного чтения ответа,
включая ожидание сервера. Соединение может повторно использоваться
между запросами.

Учитываются байты тел конечных ответов, без HTTP-заголовков
и сетевых накладных расходов. Данные читаются блоками
и не сохраняются на диск.

Результат зависит от выбранного сервера, размера файла и состояния сети.
Файл скачивается 10 раз: файл размером 20 МБ потребует около 200 МБ трафика.

## Обработка ошибок

При HTTP-ошибке, сетевой ошибке или некорректном адресе программа
выводит сообщение и завершается с кодом 1.

Тайм-аут сетевой неактивности — 30 секунд.
Он не ограничивает общую длительность скачивания.

Итоговые результаты выводятся после 10 успешных запросов.
